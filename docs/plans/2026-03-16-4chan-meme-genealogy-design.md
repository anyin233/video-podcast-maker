# 4chan Meme Genealogy Video Design

**Date**: 2026-03-16
**Video Title**: 4chan Meme进化论：互联网表情包的基因图谱
**Target Duration**: ~10min 30s
**Language**: Chinese-English mix (中文叙述 + 英文meme术语)
**Narrative Angle**: Meme Genealogy — tracing evolution trees of 4 major meme families

## Meme Families

1. **Wojak** — Feels Guy → -oomers → Soyjak → NPC
2. **Pepe** — Boy's Club → Sad/Smug → Apu/Peepo → Copium → culture war
3. **Chad** — Virgin vs Chad → Gigachad → Yes Chad / Average Enjoyer
4. **Greentext** — >be me format → classic stories → feels threads

## Color Palette by Family

- **Wojak**: Cool grey-blue (melancholy)
- **Pepe**: Green tones (on-brand)
- **Chad**: Warm gold/amber (power)
- **Greentext**: Dark terminal green on black
